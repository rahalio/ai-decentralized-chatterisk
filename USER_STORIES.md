# Chatterisk — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Listing analyst

- As a listing analyst, I want a volume-adjusted sentiment score for a token before committee, so that one viral shill thread does not look identical to sustained community concern.
- As a listing analyst, I want to open the top negative and positive comments driving the score, so that I can verify the model is not misfiring on sarcasm or ticker collisions.
- As a listing analyst, I want alerts when sentiment collapses within a time window, so that I can reopen diligence on an already-listed asset.

### Trust & safety reviewer

- As a trust & safety reviewer, I want bot-downweighted volumes called out, so that I do not treat manufactured consensus as organic.
- As a trust & safety reviewer, I want to mark a comment cluster as coordinated inauthentic behaviour, so that future scores exclude that pattern.

### Compliance officer

- As a compliance officer, I want exportable dossiers with model version and time window, so that listing decisions have an evidentiary trail.
- As a compliance officer, I want API responses to state that outputs are not investment advice, so that regulatory communications stay consistent.

### Wallet security product manager

- As a wallet PM, I want a lightweight risk badge API keyed by contract address, so that retail users see social-fraud context at send/receive time.
- As a wallet PM, I want to join Chatterisk risk with an external vulnerability scan id, so that users see both social and code risk in one view.

### Platform administrator

- As a platform administrator, I want per-workspace alert thresholds, so that listing desks and consumer apps do not share one blunt cutoff.
- As a data protection officer, I want retention and redaction controls on ingested social text, so that we can answer privacy reviews.
